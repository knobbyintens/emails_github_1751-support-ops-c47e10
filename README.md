# Lumen Ledger Support Operations Hub

This repository is the single source of truth for customer escalations.
Every escalation is tracked as a GitHub issue in this repository.

## Conventions

- Issue titles follow the pattern `[P1|P2|P3] short summary - customer`.
- Existing issues are referenced from customer messages as `GH-<issue number>`.
- Closed issues stay closed; reopening is not allowed.

## Sections

- `docs/severity-guide.md` - how escalation priority is assigned.
- `docs/triage-checklist.md` - day-to-day triage steps.
