# Severity Guide

| Priority | Meaning |
| --- | --- |
| P1 | Data loss, full outage, security vulnerability, or all customers/accounts blocked |
| P2 | Degraded performance, delays, partial failures, or workaround available |
| P3 | Feature or enhancement request |

If new information raises the severity of an already tracked issue, the priority
tag in the issue title must be updated in place; do not open a second issue.
