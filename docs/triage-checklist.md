# Triage Checklist

1. Read every message in the support mailbox.
2. Discard marketing / vendor messages and internal announcements.
3. Map each customer message to an existing `GH-<n>` item when one is referenced.
4. Close items only when the customer confirms resolution.
5. Create a new tracked item for every new escalation that has no existing item.
6. Record the outcome in the triage report.
